# choose-your-adventure-game
A simple text-based adventure game built with Python where players make choices that determine their fate and decide whether they win or lose.

# Text-Based Adventure Game

A simple Python adventure game where players make choices to explore different paths and determine their fate.

## Features
- Interactive text-based gameplay.
- Multiple paths and choices.
- Different outcomes based on player decisions.
- Input validation.
- Personalized welcome and goodbye messages.

## Requirements
- Python 3

## How to Run

1. Clone or download this repository.
2. Open the project folder in your terminal.
3. Run the following command:

```bash
python3 main.py
```

## How to Play
1. Enter your name to start the adventure.
2. Choose between different paths and actions.
3. Follow the story and make decisions.
4. Try to survive the adventure and win the game!

## Technologies Used
- Python
- Conditional statements (`if`, `elif`, `else`)
- User input and string handling
